# 2026-11-25

- 确认并验证"自定义输入波形 + D 触发器"联动：架构上 DigitalSimulator::Compile 允许 DFF.CLK 由 CLOCK/INPUT/BUTTON 直驱（DigitalSimulator.cpp:75-81），而 INPUT 波形通过 Initialize 注入 m_stimuli，因此波形可直接驱动 DFF 的 CLK 与 D。
- 在 tests/waveform_regression.h 新增实测回归：INPUT(CLK) 用 MakeSquare(0,100,50,300,false) 产生周期 100ns 方波，INPUT(D) 在 75ns 变 1、175ns 变 0，DFF.Q 在 100ns 采到 1、200ns 采到 0，Reset 后重放一致；验证通过（exit 0）。
- 用户操作方式：给两个 INPUT 分别编辑波形（一个作时钟、一个作数据），把 CLK 的 INPUT 连到 DFF 的 CLK 引脚、D 的 INPUT 连到 DFF 的 D 引脚，输出接 OUTPUT/LED 观察；停止时间需覆盖整段波形。
- 注意：DFF.CLK 不接受 CONSTANT/PROBE/门电路输出直驱；CLOCK 元件本身不接受自定义波形，做任意时钟要用 INPUT 波形。
- 修复"生成方波/脉冲报周期、高电平时间或结束时间无效"：GeneratorDialog 的默认值由 FormatTime 生成，带 " ns"/" ms" 等后缀，但 ParseTime 用 ToDouble 无法解析带单位字符串，导致原样点 OK 也报错。已在 InputWaveformDialog.cpp 的 ParseTime 中先剥离单位后缀（ns/us/ms/s），以显式单位优先，再做换算；回归新增默认值/显式单位/非法输入三个断言，exit 0。
- 用户实测还暴露输入笔误（如 "5p ns"），修复后这类非法值仍会被正确拒绝并提示，属预期行为。
