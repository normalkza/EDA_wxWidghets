# 2026-11-26

## 展示方案调研（AI 助手 + 时序电路）
- 用户准备展示小组作业，重点：API 连接的 AI 助手、时序电路。
- AI 助手入口：帮助 → AI 助手；DeepSeek API Key 在登录页填写，本地 broker（AiSession/AiApiClient → assistant_server.py）转发。
- 两种模式：给步骤（Guide，纯文字）、直接完成（Apply，生成动作/补丁）。可勾选附带画布图像、自动改进（最多 3 轮）；本地校验后整批应用，一次 Ctrl+Z 撤销。
- 离线工具箱（OfflineAssistant.cpp）不调 API，快捷命令：新建全加器/半加器/各种门、整理布局、标注输入输出、检查电路、旋转、恢复走线。
- 关键能力边界（展示前必记）：
  - `assistant_server.py:38` 旧 append_circuit 工具 TYPES 仅 8 种基本门（INPUT/OUTPUT/AND/OR/NOT/NAND/NOR/XOR），不含 DFF/COUNTER/CLOCK，所以不能让 AI“一句话搭计数器/DFF”。
  - 但新的 circuit-editor skill（`skills/circuit-editor/SKILL.md` + `assistant_skills.py`）的 capabilities 从 `ComponentRegistry::All()` 读取全部可用元件（CanvasAssistant.cpp:41-53），COUNTER/DFF/CLOCK 都在其中。因此 AI 能“修改已有计数器/时钟的字段”（update_component）、接线、加标注；但 `COMMON_COMPONENT` 字段集不含 counterMax/counterInitial/waveform（assistant_skills.py:135-136），AI 不能直接写计数器上限或波形。
  - 展示融合点建议：AI 用“直接完成”对已有电路做标注/整理/改时钟参数，或搭组合逻辑再用手工波形接 DFF；不要承诺 AI 生成时序元件。
- 建议动线：AI 助手 ~5 min（登录+桌宠、直接完成搭全加器、自动改进与撤销、追问修改）→ 时序 ~5 min（预置 DFF 电路、画 CLK/数据波形、F8 看上升沿采样、计数器设上限 9）→ 融合 ~3 min（AI 修改/标注时序电路）。
- 风险预案：网络失败切离线工具箱；预置 XML 电路文件；密钥不进录屏；用最新编译程序（波形编辑器与计数器是本轮新增）。
